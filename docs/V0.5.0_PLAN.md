## Priority 3: Re-implement Dashboard Log Scanning

### Background (from v0.4.3)
**Removed** in v0.4.3 due to **inaccurate counts:**
- Dashboard showed "19 ERR, 17 WARN" for all pods (wrong!)
- Actual logs showed "1 errors · 0 warnings"
- Violated "Truth Only™" principle

**Why it failed:**
- GetLogs() calls had incorrect namespace/pod parameters
- Counts cached/reused across different pods
- No verification that dashboard matched log view

### Requirements for Re-implementation

**Must have:**
1. ✅ **100% accuracy** - Dashboard count MUST match log view count
2. ✅ **Per-pod verification** - Each pod's counts independently verified
3. ✅ **No caching bugs** - Fresh GetLogs() call for each pod
4. ✅ **Correct parameters** - Proper namespace/pod to GetLogs()
5. ✅ **Tunable scan depth** - Respect --scan flag (default 200 lines)

### Implementation Plan

**Step 1: Create test fixture** (1 day)
```go

    // Verify dashboard count matches log view count
```

**Step 2: Implement detector** (1 day)
```go
// internal/tui/attention_signals.go
func detectLogIssues(ds datasource.DataSource, scanDepth int) []AttentionItem {
    pods, _ := ds.GetAllPods()
    
    var issues []AttentionItem
    for _, pod := range pods {
        // Fresh GetLogs() call - NO CACHING
        logs, err := ds.GetLogs("", pod.NamespaceID, pod.Name, "", false)
        if err != nil {
            continue
        }
        
        // Scan first N lines (configurable via --scan)
        scanLines := logs
        if len(logs) > scanDepth {
            scanLines = logs[:scanDepth]
        }
        
        errorCount := 0
        warnCount := 0
        for _, line := range scanLines {
            if isErrorLog(line) {
                errorCount++
            } else if isWarnLog(line) {
                warnCount++
            }
        }
        
        // Only flag significant issues
        if errorCount > 10 {
            issues = append(issues, AttentionItem{
                Title: fmt.Sprintf("%s: %d errors", pod.Name, errorCount),
                // ...
            })
        }
    }
    return issues
}
```

**Step 3: Verification harness** (1 day)
```go
// Match dashboard count with log view count
func verifyLogCounts(t *testing.T, pod Pod) {
    // Get count from dashboard detector
    dashboardCount := detectLogIssues(...)[0].errorCount
    
    // Get count from log view render
    logViewCount := renderLogsWithColors(...).errorCount
    
    // MUST MATCH
    assert.Equal(t, dashboardCount, logViewCount)
}
```

**Step 4: Integration** (1 day)

- Scan depth limits (default 200 lines)
- Pod count limits (max 10 pods)
- Skip pods with no logs
