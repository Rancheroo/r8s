## Law 3: Simplify

### Help Text Bloat Removal

**Current:** 60 lines of help output  
**Target:** 30 lines max

**Remove from root help:**
- "QUICKSTART" section (redundant with EXAMPLES)
- Detailed flag descriptions (move to command help)
- Verbose "FEATURES" list

**Simplified Help:**
```
r8s — kubectl for Rancher bundles

USAGE:
  r8s analyze ./bundle/          # Detect issues
  r8s get pods ./bundle/         # List pods  
  r8s logs ./bundle/ <pod>       # Stream logs
  r8s export ./bundle/ --format=sarif  # Export findings

COMMANDS:
  analyze    Detect issues with AI patterns
  get        Get resources (pods, nodes)
  logs       Stream pod logs
  export     Export findings (SARIF, JUnit, etc.)
  validate   Check bundle health
  ask        Ask natural language questions
  version    Show version

FLAGS:
  -v, --verbose    Verbose output
  -h, --help       Show help

Use "r8s [command] --help" for more info.
```
