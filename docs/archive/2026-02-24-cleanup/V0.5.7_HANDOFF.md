# v0.5.7 "Navigation Polish" - Development Handoff

## Quick Context

**Current Version:** v0.5.6 "Enhanced Error Diagnostics" (shipped 2026-01-06)  
**Next Release:** v0.5.7 "Navigation Polish"  
**Purpose:** Quick wins for UX before major v0.6.0 navigation refactor

## What v0.5.6 Just Shipped

- Container status diagnostics with intelligent health indicators
- BackOff frequency analysis from events
- Clean, value-only output (removed exit code noise)
- Test case: `test-notready` pod (1/2 ready) now shows container details

## v0.5.7 Scope (PRE-v0.6.0 Foundation)

### TIER 1: Quick Wins (High Value, Low Effort)

1. **Help Discovery Hint** (~30 lines)
   - Add "Press ? for help" to footer for first 3 launches
   - Track launch count in config
   - Aligns with "Show, Don't Ask" principle

2. **Expansion State Clarity** (~5 lines)
   - Change: `Showing 9/100 · [m]=expand`
   - To: `Showing 9/100 (capped) · [m]=show all 100`
   - Location: `internal/tui/attention.go`

3. **Dashboard Submenu Enter Consistency** (Medium effort)
   - From expanded submenu: Enter → Diagnostic panel (not logs)
   - Matches classic pod list behavior
   - Documented in LESSONS-LEARNED.md v0.5.6 section

### Out of Scope for v0.5.7

**DO NOT implement** (deferred to v0.6.0):
- Navigation state consolidation (needs major refactor)
- Auto-log on dashboard Enter (violates diagnostic-first design)
- Remove classic mode (serves distinct use case)
- Remove sort modes (useful for different scenarios)

## v0.6.0 Preview ("Silky Navigation")

- Single `navigateToLogs()` function
- Single `clearPodState()` helper

## Development Process

1. **Create feature branch**: `git checkout -b feature/v0.5.7`
2. **Implement TIER 1 items** (3 quick wins)
3. **Test thoroughly** with example bundle
4. **Update CHANGELOG** - move items from [Unreleased] to v0.5.7 section
5. **Update main.go** version: 0.5.6 → 0.5.7
6. **Commit and merge** to main
7. **Tag release**: `git tag -a v0.5.7 -m "v0.5.7 - Navigation Polish"`
8. **Build fresh**: `make build` (after tagging for version)

## Philosophy Alignment

- **"Show, Don't Ask"** - Help hint surfaces automatically
- **"Minimal Keys"** - 2-key triage maintained
- **"Truth Only™"** - Clear state indicators
- **Diagnostic-First** - Context before logs (v0.5.4-v0.5.6 design)

- Navigation complexity score: 8.5/10 → 9.0/10
