# r8s v1.2.1 Release Notes

**Release Date:** 2026-03-05
**Codename:** Simplify & Never Blank

## Overview

v1.2.1 focuses on reliability, UX polish, and simplification. Every command now produces clear, helpful output — no more blank screens or cryptic errors. The kubectl plugin has been removed in favor of the simpler, more powerful `r8s` CLI.

## What's New

### Never Blank Output (Issue #86)
Every r8s command now shows a helpful message instead of blank output:
- **Bundle not found** → shows the path you tried and suggests `r8s analyze ./bundle/`
- **Unknown commands** → suggests the closest match (e.g., "Did you mean `analyze`?")
- **No issues found** → confirms the bundle is healthy and suggests `r8s ask` for deeper analysis
- **Wrong argument order** → detects swapped args and shows correct usage

### Consistent Error Handling
- Unified `ExitCodeError` pattern across all commands (`get`, `analyze`, `ask`, `export`, `describe`, `logs`)
- Single error display — no more double error messages
- Regression tests added to prevent future regressions

### Smarter Argument Detection (ask command)
- Tightened swapped-argument detection to reduce false positives
- Only triggers on clear question markers (`?`, `why`, `what`, `how`)
- Valid bundle paths are no longer rejected as questions

### dmesg Path Fallbacks (Issue #88)
- `r8s validate` now checks both old (`systemlogs/dmesg`) and new (`systeminfo/dmesg`) locations
- Works correctly with both RKE2 and K3s bundle formats

### 50 User Tips
- Rotating tips in CLI output covering automation, AI queries, debugging, and integrations
- Removed inaccurate SARIF format references

## Removed

- **kubectl plugin** (`kubectl-r8s`) — removed to reduce complexity. The `r8s` CLI provides the same kubectl-compatible commands directly.

## Bug Fixes

- Fix double error display in `Execute()` for `ExitCodeError` types
- Fix `get` command silent exit when bundle not found
- Fix `analyze` command double error display on missing bundle
- Clean up fake command aliases from `isKnownCommand`
- Tighten pod-stuck-terminating regex to avoid false matches
- Fix `describe` argument ordering heuristics
- Output success messages ("No issues found") to stdout instead of stderr
- Remove unsupported SARIF/JUnit tips from user tips

## Test Results

- All unit tests passing (23 tests in `cmd/` package)
- 4 new regression tests for bundle-not-found error handling
- 6 new dmesg fallback tests
- Manual test coverage: symlinks, unicode, long names, edge cases

## Upgrade Notes

- If you use `kubectl-r8s`, switch to `r8s` directly — all commands are identical
- Exit codes unchanged: 0=healthy, 1=issues found, 2=error
- All export formats work as before (JSON, YAML, Markdown)

## Quick Start

```bash
# Download
curl -L -o r8s https://github.com/Rancheroo/r8s/releases/download/v1.2.1/r8s-v1.2.1-linux-amd64
chmod +x r8s && sudo mv r8s /usr/local/bin/

# Analyze a bundle
r8s analyze ./support-bundle/

# Ask questions
r8s ask ./support-bundle/ "why is my pod crashing?"
```
