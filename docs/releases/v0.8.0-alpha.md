# r8s v0.8.0-alpha Release Notes

**Release Date:** 2026-02-18
**Codename:** kubectl for Rancher bundles

## Overview

v0.8.0-alpha introduces the CLI-first architecture — kubectl-compatible commands that work offline with Rancher support bundles.

## New Features

### kubectl-Compatible Commands
- `r8s get pods|nodes|ns|deploy|svc|events` — List resources
- `r8s logs <pod>` — Stream logs from bundle
- `r8s describe pod|node|ns` — Detailed inspection

### Bundle Analysis
- `r8s analyze` — Pattern detection
- `r8s validate` — Health checking
- `r8s generate prompt` — AI-ready diagnostics

## Bug Fixes

- ✅ r8s logs works with RKE2 flat bundle structure
- ✅ Invalid output formats now error properly
- ✅ Pod log counting in health check

## Breaking Changes

- Removed: Full TUI mode (-9,360 lines)
- Changed: Default command is now `analyze`

## Test Results

56 tests: 52 passed, 0 failed

./r8s get pods ./bundle/
