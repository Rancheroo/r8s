# r8s v1.3.3 Release Notes

**Release Date:** March 5, 2026
**Focus:** AI Context Generation

This release introduces the powerful `generate prompt` command, designed to bridge the gap between static support bundles and modern AI tools like ChatGPT, Claude, and OpenCode.

## 🚀 Key Highlights

### 🧠 AI Context Generation
The new `r8s generate prompt` command intelligently packages your support bundle into a format optimized for LLM context windows.

- **Smart Summarization**: Automatically extracts critical data:
  - Cluster health (Node status, version)
  - Failing pods (CrashLoopBackOff, OOMKilled, etc.)
  - Relevant logs (tail of failing containers)
  - Warning events
- **Optimized for LLMs**: Formatted in Markdown for easy copy-pasting or piping.
- **Privacy First**: You control where the data goes. Pipe it to a local model or a secure enterprise instance.

### 🛠️ Integrations
- **OpenCode Support**: Pipe directly to OpenCode for interactive debugging:
  ```bash
  r8s generate prompt ./bundle/ | opencode run
  ```

## 📦 Usage

**Generate a prompt for ChatGPT/Claude:**
```bash
r8s generate prompt ./bundle/ > context.md
# Copy content of context.md to your AI assistant
```

**Interactive Debugging with OpenCode:**
```bash
r8s generate prompt ./bundle/ | opencode run
```
