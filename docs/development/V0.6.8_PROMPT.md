**PROPOSED FORMAT**:
```
Current:  Failed: lgsp1skbtd12001.gso.aexp.com failed to pull image "registry.rancher...
          agent:v2.8.5": rpc error: code = DeadlineExceeded desc = failed to resolve 
          reference "registry.rancher.com/rancher/rancher-agent:v2.8.5": failed to do...
          
Proposed: Failed: Image pull timeout - registry.rancher.com/rancher/rancher-agent:v2.8.5
          └─ rpc error: DeadlineExceeded (truncated)
```

**IMPLEMENTATION**:
```go
func truncateEventMessage(msg string, maxLen int) string {
    if len(msg) <= maxLen {
        return msg
    }
    
    // Smart truncation: keep error type and key details
    // Option 1: Beginning + end with ellipsis
    keep := (maxLen - 5) / 2  // Reserve 5 for " ... "
    return msg[:keep] + " ... " + msg[len(msg)-keep:]
    
    // Option 2: Beginning only with (truncated)
    return msg[:maxLen-13] + " (truncated)"
}
```

**SUCCESS CRITERIA**:
- ✅ Event messages ≤80 characters per line
- ✅ Key info preserved (event type, resource, error code)
- ✅ "(truncated)" indicator when message is cut
- ✅ Container status section visible (not hidden by events)
- ✅ Diagnostic panel scannable

if item.ResourceType == "kubelet" {
    nodeName := extractNodeFromKubeletItem(item)
    pods := dataSource.GetPodsByNode(nodeName)
    item.AffectedPods = pods

// Node pressure → Pods scheduled on node
if item.ResourceType == "node" {
    pods := dataSource.GetPodsByNode(item.NodeName)
    item.AffectedPods = pods
