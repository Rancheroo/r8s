## Implementation Notes

### Backward Compatibility Strategy
Path resolver now provides multiple paths and tries them in order:
```go
// GetMemoryPaths returns: [systeminfo/memory, systeminfo/freem]
// GetDmesgPaths returns: [systeminfo/dmesg, systemlogs/dmesg]

path := FindFirstExisting(resolver.GetMemoryPaths())
```
