## Sprint Goals

### Goal 1: Never Blank Output
**Every command failure must show helpful guidance.**

| Scenario | Current | Desired |
|----------|---------|---------|
| Wrong arg order | Silent/unclear error | `Usage: r8s ask <bundle> <question>` |
| Missing bundle | Error | `Bundle not found. Try: r8s analyze ./bundle/` |
| Unknown command | Generic error | `Unknown command. Did you mean 'analyze'?` |
| Empty result | Nothing | `No issues found. Try 'r8s ask' for natural language queries` |

### Goal 2: Simplify Analysis Output
**Current:** Busy loading messages, multiple tips, cowboy theme  
**Desired:** Clean progress indicator, ONE inspiring tip

**Before:**
```
🤠 Howdy partner, analyzing your bundle...
[⠋] Scanning for issues...
💡 Did you know r8s can export to SARIF?
[⠙] Parsing Kubernetes resources...
💡 Try 'r8s ask' for natural language
[⠹] Checking patterns...
💡 Use r8s in CI/CD pipelines
```

**After:**
```
Analyzing bundle... [3/3] ✓
Found 7 critical, 225 warning issues

💡 Tip: Use 'r8s export --format=sarif' for CI/CD integration
```

### Goal 3: Repo Documentation Cleanup (Issue #89)
- Archive old docs from v0.x era
- Consolidate redundant files
- Create clear README structure
- One source of truth per topic
