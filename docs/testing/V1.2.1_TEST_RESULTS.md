### MED-2: Describe Arg Ordering — PARTIAL PASS

| # | Command | Expected | Result | Pass |
|---|---------|----------|--------|------|
| 5.1 | `r8s describe pod <bundle> name` | Works (kind first) | "No resources found" (correct parse) | ✅ |
| 5.2 | `r8s describe <bundle> pod name` | Works (bundle first, swap detected) | "No resources found" (correct parse) | ✅ |
| 5.3 | `r8s describe helmcharts.helm.cattle.io <bundle> my-chart` | CRD with dots works | "No resources found" (no false path detection) | ✅ |
| 5.4 | `r8s describe <bundle>` (1 arg) | Error message | "accepts between 2 and 3 arg(s)" | ✅ |

**FIND-3:** The heuristic checks `args[0]` for `/` to detect swapped order. This handles `./bundle pod name` ✅ but NOT `pod name ./bundle` (where `args[2]` is the path). Users writing `describe pod my-pod ./bundle` get "Bundle not found: 'my-pod'" because the code treats `my-pod` as the bundle path. The heuristic should also check if `args[2]` looks like a path when `args[1]` does not.

**Edge case — dots in directory path:** `describe pod my-pod /tmp/v1.2.3/bundle` — same issue (shows "Bundle not found: 'my-pod'"). The path is in position 3, not detected.

## New Findings (v1.2.2 Candidates)

### FIND-1: REGRESSION — ExitCodeError Double-Displays Error (Medium)
**File:** `cmd/root.go` (83-87)  
**Symptom:** `r8s analyze <bundle>` now shows both its own output AND `✗ Error: analysis found 7 critical issues` from `ShowFriendlyError`.  
**Root Cause:** The fix for CRITICAL-1 added `ShowFriendlyError(err)` to the `ExitCodeError` branch. But `ExitCodeError` is used for intentional exits (issues found = exit 1), not actual errors. The command already displayed its results.  
**Fix:** Remove `ShowFriendlyError(err)` from the `ExitCodeError` branch:
```go
if exitErr, ok := err.(*ExitCodeError); ok {
    os.Exit(exitErr.Code)  // Just exit, no extra error display
}
ShowFriendlyError(err)
os.Exit(ExitError)
```

### FIND-2: Hardcoded 'analyze' Fallback for Unknown Commands (Low)
**File:** `cmd/root.go` (~line 75)  
**Symptom:** Typos not in `CommandSuggestions` (e.g., `validte`, `describ`, `dscribe`) always suggest 'analyze' regardless of similarity.  
**Fix:** Replace hardcoded fallback with `ShowUnknownCommandError(firstArg)` which uses Levenshtein distance via `findSimilarCommands()`.

### FIND-3: Describe Arg Swap Only Checks args[0] (Low)
**File:** `cmd/describe.go` (120-131)  
**Symptom:** `describe pod name ./bundle` misparses because the heuristic only detects paths in `args[0]`, not `args[2]`.  
**Fix:** Also check if `args[2]` contains `/` when `args[1]` doesn't — swap `args[1]` and `args[2]` in that case.

### FIND-4: Error Message Could Be Friendlier for Missing Args (Low)
**Symptom:** `r8s ask <bundle>` shows raw Cobra message "requires at least 2 arg(s), only received 1" instead of a contextual hint like "Usage: r8s ask <bundle> 'your question'"  
**Fix:** Add custom `Args` validator or pre-RunE hook that shows contextual usage for each command.
